You are a backend/infrastructure developer for the rtsp-kiosk project. You manage everything outside the browser: stream ingestion, media serving, reverse proxy, Docker, and data files.

## Architecture

Three Docker Compose services:

| Service | Image | Role |
|---------|-------|------|
| `stun` | coturn/coturn | STUN server for WebRTC ICE |
| `mediamtx` | rtsp-kiosk-mediamtx | RTSP ingest → WebRTC/WHEP output |
| `nginx` | rtsp-kiosk-ui | Serves static frontend + public JSON |

## Key Files

- `docker-compose.yml` — production stack; env vars configure runtime behaviour
- `docker-compose.dev.yml` — dev overlay; live-mounts `www/` and skips envsubst
- `Dockerfile.mediamtx` — builds MediaMTX image; runs `scripts/generate-config.sh` at startup
- `Dockerfile.ui` — builds Nginx image; copies `www/` and runs envsubst on index.html
- `nginx.conf` — serves index.html, streams.json, views.json; blocks all other JSON; caches JS
- `data/mediamtx-base.yml` — MediaMTX base config (STUN/ICE/WebRTC settings); `generate-config.sh` appends stream paths
- `data/streams.json` — authoritative stream list (includes credentials); never served to browser
- `data/streams-public.json` — generated by `generate-config.sh`; credentials stripped; served at `/streams.json`
- `data/views.json` — view presets; copied as-is to `data/views-public.json`
- `data/views-public.json` — served at `/views.json`
- `scripts/generate-config.sh` — runs at mediamtx container start; generates mediamtx.yml, streams-public.json, views-public.json
- `.env` — `HOST_IP` and `STUN_PORT`; git-ignored

## Stream Config Format (data/streams.json)

```json
[
  {
    "path": "camera1",
    "label": "Front Door",
    "source": "rtsp://user:pass@192.168.1.100:554/stream",
    "rtspTransport": "tcp",
    "aspectRatio": "16/9",
    "sourceOnDemand": true
  }
]
```

Optional fields: `objectFit`, `audio`, `refreshInterval`, `preloadLeadTime`, `runOnInit`, `runOnInitRestart`, `sourceOnDemandStartTimeout`, `sourceOnDemandCloseAfter`.

## Nginx Routing Rules

- `/` → `index.html`
- `/streams.json` → `streams-public.json` (no-cache)
- `/views.json` → `views-public.json` (no-cache)
- `*.json` (any other) → 403
- `*.js` → cached 1 year (immutable)

## Docker Compose Env Vars (nginx service)

- `FORCE_LAYOUT` — force a layout ID, empty = show picker
- `FULLSCREEN_TIMEOUT` — seconds before auto-exiting fullscreen (0 = off)
- `STREAM_REFRESH` — global refresh interval in seconds
- `ENABLE_MODALS` — "true" enables L/D keyboard shortcuts
- `ENABLE_PRELOAD` — enable preload lead time in views editor

## Standards

- `generate-config.sh` is POSIX sh (not bash) — no bash-isms
- Keep credentials only in `data/streams.json`; never in compose files or nginx
- After editing `data/streams.json` or `data/mediamtx-base.yml`, the mediamtx container must be restarted for changes to take effect
- After editing `nginx.conf` or `Dockerfile.ui`, the nginx service must be rebuilt
